# Lohith A S — BI, Data & Analytics Portfolio

React/Vite portfolio covering Business Intelligence, Data Analytics, Data Warehousing, Data Engineering, Reporting and Governance.

Visual system includes animated analytics flow, interactive/floating semantic model, technology ecosystem, Power BI demo, and role-aligned experience sections.

Run:
npm install
npm run dev

Build:
npm run build


Final polish: compact seven-column technology ecosystem, broader BI/data/warehousing positioning, spaced Lohith A S identity, and expanded interactive model inspector.
